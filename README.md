# โฮงชาฮักมี (HongCha Hugme)

เว็บไซต์ร้านขายชาออนไลน์ พร้อมระบบตะกร้าสินค้า, checkout (จำลองการชำระเงิน), รีวิวสินค้า และระบบสมาชิกที่ใช้งานได้จริง

## Requirements

- [Docker Desktop](https://www.docker.com/products/docker-desktop/) (รวม Docker Compose มาให้แล้ว)

## เริ่มต้นใช้งาน

รันคำสั่งเดียวจากโฟลเดอร์โปรเจกต์:

```bash
docker compose up --build
```

รอสักครู่ (ครั้งแรกจะโหลด image ประมาณ 2-3 นาที ครั้งต่อไปจะเร็วขึ้นมาก) ระบบจะสร้างฐานข้อมูลและใส่ข้อมูลสินค้าตัวอย่างให้อัตโนมัติ จากนั้นเปิดเบราว์เซอร์ไปที่:

```
http://localhost:8090
```

## คำสั่งที่ใช้บ่อย

```bash
docker compose up -d          # รันแบบ background
docker compose logs -f        # ดู log แบบ real-time
docker compose down           # ปิดการทำงานทั้งหมด
docker compose down -v        # ปิด + ล้างข้อมูลในฐานข้อมูลทั้งหมด (เริ่มใหม่)
```

## หมายเหตุสำหรับ Demo

- **การชำระเงินเป็นการจำลอง** ไม่ได้ต่อ payment gateway จริง — ใช้เลขบัตรอะไรก็ได้ (อย่างน้อย 12 หลัก) เพื่อทดสอบ ถ้าอยากทดสอบกรณี "บัตรถูกปฏิเสธ" ให้ใช้เลขบัตรที่ลงท้ายด้วย `0002`
- ปุ่มล็อกอินด้วย Google/Facebook เป็น **โหมดทดลอง** สร้างบัญชีทดสอบให้อัตโนมัติ ยังไม่ได้เชื่อมต่อ OAuth จริง
- สลับภาษาไทย/อังกฤษได้จากเมนู "บัญชีของฉัน" มุมขวาบนหลังล็อกอิน
